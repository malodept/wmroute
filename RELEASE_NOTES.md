# v0.1.0-preprint

First curated public release candidate for the preprint:

**Routing World-Model Compute from Predicted Consequences: A Paired Exact-Reset Evaluation**

Included:

- current 20-page preprint and LaTeX source;
- static project page;
- reusable `wmroute` Python package;
- compact per-state records, arrays, router seals, and confirmation manifests;
- prospective prediction-versus-current-DINO confirmation;
- paper-facing table and figure builders;
- 27 regression, theory, bootstrap, sealing, and replay tests;
- GitHub Actions verification on Python 3.10 and 3.12.

The release intentionally excludes heavy training banks, DINOv2 weights,
upstream world-model checkpoints, complete simulator assets, and the original
HPC runtime. It supports paper-facing recomputation rather than full physical
outcome regeneration.

rights review.
