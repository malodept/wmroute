# GitHub setup

The package is ready to become the contents of `https://github.com/malodept/wmroute`.

## Recommended sequence

1. Create an empty **private** GitHub repository named `wmroute` without adding a README, licence, or `.gitignore`.
2. Push this release candidate.
3. Wait for GitHub Actions to pass.
4. Enable GitHub Pages: **Settings → Pages → Deploy from a branch → `main` → `/docs`**.
5. Inspect the README, project page, PDF link, and generated figures.
6. Change repository visibility to **Public**.
7. Create the release tag `v0.1.0-preprint`.

Exact terminal commands are provided with the release handoff message.
